# r4wm.github.io

Personal site of Raymond Mintz, served by GitHub Pages from `master` as plain static files (no Jekyll; see `.nojekyll`).

| Path | What |
|---|---|
| `index.html`, `site.css` | home page |
| `resume/index.html` | resume, generated from the same source as the PDF |
| `Raymond_Mintz_Resume.pdf`, `Raymond_Mintz_Resume.txt` | downloads |
| `404.html` | not-found page |

To update the resume, regenerate the TXT/HTML/PDF set, copy the PDF and TXT here, and copy the HTML to `resume/index.html` with the toolbar links pointing at `/` and the root downloads.
